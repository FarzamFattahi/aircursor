# Security and privacy

AirCursor controls the system pointer and reads frames from a local webcam. Camera frames are processed in memory and are not intentionally saved or transmitted.

Report a vulnerability privately through GitHub's security-advisory feature. Do not include personal camera images, logs containing personal information, or proof-of-concept code that could cause unintended input on another person's computer.

The emergency stop is `Ctrl+Alt+Esc`. All error and shutdown paths should release any held mouse button before camera or application teardown.
